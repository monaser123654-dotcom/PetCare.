PetCare - ملفات الموقع / التطبيق (PWA)

ارفع كل الملفات دي مع بعض في نفس المكان (جذر الـ repository على GitHub Pages):
index.html, manifest.json, sw.js, الأيقونات الأربعة PNG, .nojekyll

بعد النشر: افتح الرابط من كروم على الموبايل > "تثبيت التطبيق".
لو كان التطبيق متثبت قبل كده باسم أليف: امسحه وثبّته تاني عشان الاسم والأيقونة الجداد يظهروا.
مهم: اسمح بـ origin بتاع GitHub Pages (CORS) في webhooks الـ n8n التلاتة:
aleef-scan, Aleef, aleef-behavior   (أسماء الـ webhooks متغيّرتش عشان الاتصال يفضل شغال)
